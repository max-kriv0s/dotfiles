# Neovim — Шпаргалка

Модальный редактор — в разных режимах клавиши делают разное.

---

## Дополнительная изолированная настройка

```bash
# Текущий `nvim` остается основным:
#   nvim
#   nv

# 1. Создать отдельный конфиг в dotfiles рядом с основным `nvim`
# Структура совместима со stow, но сейчас stow не нужен:
# ~/dotfiles/nvim-test/.config/nvim-test
mkdir -p ~/dotfiles/nvim-test/.config/nvim-test
touch ~/dotfiles/nvim-test/.config/nvim-test/init.lua
mkdir -p ~/dotfiles/nvim-test/.config/nvim-test/lua

# 2. Подключить конфиг в ~/.config через symlink
ln -s ~/dotfiles/nvim-test/.config/nvim-test ~/.config/nvim-test

# 3. Проверить symlink
ls -la ~/.config | grep nvim-test

# 4. Запускать тестовую настройку
NVIM_APPNAME=nvim-test nvim

# 5. Добавить alias в shell-конфиг
alias nv-test='NVIM_APPNAME=nvim-test nvim'

# После этого запускать так:
nv-test

# Где что лежит:
# ~/dotfiles/nvim-test/.config/nvim-test  # конфиг, хранится в git
# ~/.config/nvim-test                     # symlink на конфиг
# ~/.local/share/nvim-test                # плагины и данные
# ~/.local/state/nvim-test                # состояние
# ~/.cache/nvim-test                      # кеш

# Посмотреть размер конфига
du -sh ~/dotfiles/nvim-test

# Посмотреть размер служебных каталогов
du -sh ~/.local/share/nvim-test ~/.local/state/nvim-test ~/.cache/nvim-test

# Посмотреть размер всех neovim-каталогов
du -sh ~/.config/nvim* ~/.local/share/nvim* ~/.local/state/nvim* ~/.cache/nvim*
```

## Критичные параметры

| Параметр       | Значение | Зачем нужен                                                               |
| -------------- | -------- | ------------------------------------------------------------------------- |
| `mapleader`    | `Space`  | главная клавиша для наших маппингов: например `Space+w`, `Space+ff`       |
| `timeoutlen`   | выкл.    | ВАЖНО: если раскомментировать `1500`, можно дольше ждать между клавишами  |
| `persist_size` | `true`   | toggleterm: запоминать измененный размер split-терминала в текущей сессии |

## Буферы, окна, вкладки

| Что     | Что значит в Neovim                                                |
| ------- | ------------------------------------------------------------------ |
| Буфер   | открытый файл или терминал в памяти                                |
| Окно    | область экрана/split, где показан буфер                            |
| Вкладка | отдельная раскладка окон; одна вкладка может содержать много split |

| ------- | --------- | ---------------- |
| Normal  | `Esc`     | --               |
| Insert  | `i`       | -- INSERT --     |
| Visual  | `v`       | -- VISUAL --     |

## Основные команды (Normal режим)

### Сохранение и выход

| Команда   | Действие                |
| --------- | ----------------------- |
| `:w`      | сохранить               |
| `:q`      | выйти                   |
| `:wq`     | сохранить и выйти       |
| `:q!`     | выйти без сохранения    |
| `:cq`     | выйти с кодом ошибки    |
| `Space+w` | сохранить (наш маппинг) |
| `Space+q` | закрыть буфер           |

### Навигация (Motion)

| Клавиша    | Действие                                                             |
| ---------- | -------------------------------------------------------------------- |
| `h/j/k/l`  | влево/вниз/вверх/вправо                                              |
| стрелки    | то же самое                                                          |
| `w`        | перемещение вперед по словам                                         |
| `W`        | перемещение вперед игнорируя все символы кроме пробел                |
| `e`        | перемещение вперед по словам на конец слова                          |
| `E`        | перемещение вперед на конец слова игнорируя все символы кроме пробел |
| `b`        | перемещение назад по словам                                          |
| `B`        | перемещение назад игнорируя все символы кроме пробел                 |
| `0`        | перемещение в начало строки                                          |
| `$`        | перемещение в конец строки                                           |
| `_`        | перемещение к первому непробельному символу строки                   |
| `- / +`    | перемещение к предыдущей/следующей строке                            |
| `gg`       | начало файла                                                         |
| `G`        | конец файла                                                          |
| `Ctrl+D`   | прокрутить вниз                                                      |
| `Ctrl+U`   | прокрутить вверх                                                     |
| `/{текст}` | поиск вперёд                                                         |
| `n/N`      | следующее/предыдущее совпадение                                      |
| `{ / }`    | перемещение к предыдущему/следующему абзацу                          |
| `%`        | перемещение между парными скобками/конструкциями                     |
| `[{ / ]}`  | перемещение к предыдущей `{` или следующей `}`                       |

### Переходы по истории мест

| Клавиша  | Действие                              |
| -------- | ------------------------------------- |
| `Ctrl+O` | перейти назад по jump list            |
| `Ctrl+I` | перейти вперед по jump list           |
| `g;`     | перейти к предыдущему месту изменения |
| `g,`     | перейти к следующему месту изменения  |

`Ctrl+I` в терминале часто совпадает с `Tab`; если не срабатывает, попробуй `Tab`.

### Комбинации

| Комбинация          | Действие                                                                               |
| ------------------- | -------------------------------------------------------------------------------------- |
| `3W`                | выполнить 3 раза перемещение вперед игнорируя все символы кроме пробел                 |
| `14G`               | переход на указанную строку. в данном примере на 14 строку                             |
| `fg`                | переход к первому найденному символу `g` в текущей строке                              |
| `; / ,`             | повторить последний поиск через `f`/`F`/`t`/`T` вперед или назад                       |
| `d + N + w/b/e`     | удаляет N слов вперед / назад /до пробела. без N одно слово                            |
| `c + N + w/b/e`     | удаляет N слов вперед / назад /до пробела с переходом в режим insert. без N одно слово |
| `d + i + w`         | удаляет слово, например если курсор в его середине                                     |
| `d + i + t`         | удалить текст внутри HTML/XML-тега                                                     |
| `" + N + y + i + t` | скопировать текст внутри тега и поместить в регистр N                                  |

## Работа с текстом

| Клавиша               | Действие                                                                                       |
| --------------------- | ---------------------------------------------------------------------------------------------- |
| `x`                   | удаление одного элемента                                                                       |
| `Shift + r`           | режим замены                                                                                   |
| `*`                   | встать на слово и нажать \* будут выделены все аналогичные слова. n - далее; shift + n - назад |
| `:nohlsearch`         | отменяет подсветку                                                                             |
| `/`                   | войти в режим поиска, тут можно вводить слова и regex                                          |
| `cgn`                 | войти в режим корректировки "c", "gn" найти последнее что мы выделили в поиске                 |
| `dgn`                 | удалить "d", "gn" найти последнее что мы выделили в поиске                                     |
| `:s/word/new_word/g`  | заменить слово word на new_word, "g" глобально в рамках строки                                 |
| `:%s/word/new_word/g` | заменить слово word на new_word, "g" глобально во всем файле (буфере)                          |

| Клавиша | Действие                      |
| ------- | ----------------------------- |
| `i`     | вставка перед курсором        |

## Visual режим (выделение и копирование)

| Клавиша     | Действие                                   |
| ----------- | ------------------------------------------ |
| `v`         | выделение символов                         |
| `Shift + v` | выделение строк                            |
| `ggVG`      | выделить всё                               |
| `y`         | скопировать в системный буфер              |
| `d`         | вырезать                                   |
| `p`         | вставить                                   |
| `u`         | меняет регистр выделенного текста на Lower |
| `Shift + u` | меняет регистр выделенного текста на Upper |
| `>`         | сдвинуть выделенные строки вправо          |
| `<`         | сдвинуть выделенные строки влево           |

## Буфер обмена

`clipboard = "unnamedplus"` настроен — обычные `y` и `p` работают с системным буфером напрямую.
Скопировать и вставить в другое приложение:
v → выделить → y → Cmd+V в другом приложении
Вставить из другого приложения в nvim:
i → Cmd+V

## Установка LSP и CLI-инструментов

Для установки language server, formatter и linter используется `mason.nvim`.

| Команда         | Действие                             |
| --------------- | ------------------------------------ |
| `:Mason`        | открыть интерфейс Mason              |
| `g?`            | помощь внутри Mason                  |
| `i`             | установить выбранный пакет           |
| `X`             | удалить выбранный пакет              |
| `Ctrl+f`        | применить фильтр по языку            |
| `:MasonInstall` | установить пакеты командой из Neovim |

Важно: имя пакета в Mason и имя LSP в `vim.lsp.config()` могут отличаться.
Например Mason ставит `lua-language-server`, а в конфиге включается `lua_ls`.

### Примеры установки

```vim
" Lua / Neovim config
:MasonInstall lua-language-server stylua

" JavaScript / TypeScript
:MasonInstall typescript-language-server eslint-lsp prettier

" Go
:MasonInstall gopls gofumpt goimports

" Python
:MasonInstall pyright ruff black

" Shell / YAML / JSON / Markdown
:MasonInstall bash-language-server shellcheck shfmt yaml-language-server json-lsp marksman
```

| Язык/инструмент | Mason-пакет                  | Имя LSP в конфиге |
| --------------- | ---------------------------- | ----------------- |
| Lua             | `lua-language-server`        | `lua_ls`          |
| JS/TS           | `typescript-language-server` | `ts_ls`           |
| ESLint          | `eslint-lsp`                 | `eslint`          |
| Go              | `gopls`                      | `gopls`           |
| Python          | `pyright`                    | `pyright`         |
| Ruff            | `ruff`                       | `ruff`            |
| Bash            | `bash-language-server`       | `bashls`          |
| YAML            | `yaml-language-server`       | `yamlls`          |
| JSON            | `json-lsp`                   | `jsonls`          |
| Markdown        | `marksman`                   | `marksman`        |

В репе языки ставятся отдельно: Node через `fnm`, Python через `uv`, Go через системный пакет `go`/`golang`.
Mason ставит только инструменты для Neovim, а не сами рантаймы языка.

Работает в буферах, где подключился language server.

| Клавиша      | Действие                    |

### Diagnostics

Inline-текст ошибок включается в `nvim/.config/nvim/lua/plugins/neo-tree.lua`.
Чтобы скрыть текст ошибок в строках и оставить только signs/подчёркивания, поменять:

```lua
virtual_text = false
```
