# Neovim — основы

Как устроен редактор и как им пользоваться. Полный список клавиш — в
[keys.md](keys.md), порядок освоения — в [edu.md](edu.md).

`<leader>` — клавиша-префикс, какая именно назначена, указано в начале
[keys.md](keys.md).

---

## Режимы

Главное отличие от привычных редакторов: одни и те же клавиши делают разное
в зависимости от режима. В Normal `d` удаляет, в Insert печатает букву «d».

| Режим | Как войти | Что видно внизу | Для чего |
| --- | --- | --- | --- |
| Normal | `Esc` | ничего | перемещение и команды правки |
| Insert | `i`, `a`, `o` | `-- INSERT --` | набор текста |
| Visual | `v`, `V` | `-- VISUAL --` | выделение |
| Command | `:` | `:` в строке снизу | команды вроде `:w` |
| Terminal | автоматически | `-- TERMINAL --` | ввод в терминале |

Normal — основной. В нём проводят большую часть времени, а в Insert заходят,
чтобы набрать текст, и сразу выходят.

Выход в Normal — `Esc` или `jj`.

---

## Запуск

```bash
nvim file.txt    # открыть файл
nvim .           # открыть текущий каталог
nvim             # пустой буфер
nv               # алиас, пока идёт работа над новой сборкой
```

## Перемещение

Курсор двигают, не отрывая рук от домашнего ряда.

| Клавиша | Действие |
| --- | --- |
| `h` / `j` / `k` / `l` | влево / вниз / вверх / вправо |
| `w` / `b` | на слово вперёд / назад |
| `e` | в конец слова |
| `W` / `B` / `E` | то же, но словом считается всё до пробела |
| `0` / `$` | в начало / конец строки |
| `_` | к первому непробельному символу |
| `gg` / `G` | в начало / конец файла |
| `14G` | на строку 14 |
| `{` / `}` | по абзацам |
| `%` | к парной скобке |
| `Ctrl+d` / `Ctrl+u` | полэкрана вниз / вверх |

**Счётчик перед командой повторяет её:** `3w` — на три слова вперёд, `5j` — на
пять строк вниз.

### Поиск как способ перемещения

| Клавиша | Действие |
| --- | --- |
| `/текст` | искать вперёд |
| `?текст` | искать назад |
| `n` / `N` | следующее / предыдущее совпадение |
| `*` | искать слово под курсором |
| `fд` | к ближайшей букве «д» в строке |
| `;` / `,` | повторить поиск буквы вперёд / назад |
| `<leader>nh` | убрать подсветку найденного |

Поиск часто быстрее движений: до нужного места в экране доскакать по `/имя`
короче, чем считать строки.

### Подвинуть экран, не двигая курсор

| Клавиша | Действие |
| --- | --- |
| `zz` | строку с курсором в центр окна |
| `zt` | строку с курсором наверх |
| `zb` | строку с курсором вниз |

Настройка `scrolloff = 8` держит восемь строк между курсором и краем окна,
но у начала и конца файла отступ схлопывается — прокручивать за последнюю
строку Vim не умеет. `zz` решает это в любой момент.

### Возврат туда, где были

| Клавиша | Действие |
| --- | --- |
| `Ctrl+O` | назад по списку прыжков |
| `Ctrl+I` | вперёд |
| `Ctrl+^` | к предыдущему буферу |
| `g;` / `g,` | к предыдущему / следующему месту правки |

`Ctrl+O` работает и между файлами: ушли из `app.ts` в `utils.ts`, оттуда ещё
глубже — двумя нажатиями вернулись к началу.

## Правка текста

Команда собирается как **действие + объект или движение**.

| Действие | Что делает |
| --- | --- |
| `d` | удалить |
| `c` | удалить и перейти в Insert |
| `y` | скопировать |
| `v` | выделить |
| `=` | выровнять отступы |

Примеры: `dw` удалить слово, `d$` до конца строки, `dd` строку целиком,
`c3w` заменить три слова, `yy` скопировать строку.

| Клавиша | Действие |
| --- | --- |
| `x` | удалить символ |
| `p` / `P` | вставить после / до курсора |
| `u` | отменить |
| `Ctrl+r` | вернуть отменённое |
| `.` | повторить последнее действие |
| `R` | режим замены |

**`.` — самая недооценённая клавиша.** Исправили слово, перешли к следующему
такому же по `n`, нажали `.` — повторилось.

### Замена

| Команда | Действие |
| --- | --- |
| `:s/было/стало/g` | заменить в текущей строке |
| `:%s/было/стало/g` | заменить во всём файле |
| `:%s/было/стало/gc` | то же с подтверждением каждой замены |
| `cgn` | заменить следующее совпадение поиска, дальше повторять `.` |

Для переименования в коде лучше `<leader>rn` — оно понимает структуру и не
трогает совпадения в строках и комментариях.

## Insert

| Клавиша | Куда встанет курсор |
| --- | --- |
| `i` | перед курсором |
| `a` | после курсора |
| `I` / `A` | в начало / конец строки |
| `o` / `O` | новая строка ниже / выше |
| `jj` или `Esc` | выйти в Normal |

Выделять в Insert нельзя — для этого Visual.

### Правка, не выходя в Normal

Эти клавиши работают в Insert изначально, настраивать ничего не нужно.

| Клавиша | Действие |
| --- | --- |
| `Ctrl+h` | стереть символ слева, как Backspace |
| `Ctrl+w` | стереть слово слева |
| `Ctrl+u` | стереть строку до курсора |
| `Ctrl+j` | перенос строки, как Enter |

`Ctrl+o` выполняет **одну** команду Normal и сразу возвращает в Insert:
`Ctrl+o` `A` — в конец строки, `Ctrl+o` `0` — в начало, `Ctrl+o` `2h` — на два
символа влево. Нужен, когда правка мелкая и выходить в Normal ради неё не
хочется.

Основной приём всё-таки другой: набрать строку целиком, выйти в Normal и
править оттуда — `ciw` заменить слово, `f(` прыгнуть к символу, `.` повторить
последнюю правку.

## Visual

| Клавиша | Действие |
| --- | --- |
| `v` | выделение по символам |
| `V` | по строкам |
| `Ctrl+v` | прямоугольный блок |
| `ggVG` | выделить весь файл |
| `y` / `d` | скопировать / вырезать |
| `>` / `<` | сдвинуть вправо / влево, выделение сохраняется |
| `u` / `U` | в нижний / верхний регистр |
| `gc` | закомментировать |

Прямоугольное выделение `Ctrl+v` удобно, когда нужно дописать одно и то же в
начало нескольких строк: выделили столбец, `I`, набрали текст, `Esc`.

## Текст-объекты

Вместо «выделить от сих до сих» — назвать то, что нужно изменить. Курсор может
стоять в любом месте объекта.

Префикс `i` — «внутри» (inner), без обёртки. `a` — «вокруг» (around), вместе
с обёрткой.

| Объект | Что берёт |
| --- | --- |
| `iw` / `aw` | слово / слово с пробелом |
| `i"` / `a"` | внутри кавычек / вместе с кавычками |
| `i(` / `a(` | внутри скобок / вместе со скобками |
| `i{` / `a{` | внутри фигурных скобок |
| `it` / `at` | внутри HTML-тега / вместе с тегом |
| `ip` / `ap` | абзац |

### Объекты по структуре кода

Работают там, где установлен парсер treesitter — ts, tsx, vue, js, python, go,
lua и остальные из списка в `lua/plugins/treesitter.lua`.

| Объект | Что берёт |
| --- | --- |
| `af` / `if` | функция целиком / её тело |
| `ac` / `ic` | класс целиком / его тело |
| `aa` / `ia` | аргумент с запятой / сам аргумент |

Примеры: `vaf` выделить функцию, `dif` очистить тело, `caf` заменить целиком,
`daa` удалить аргумент, не оставив висящей запятой.

Если курсор не внутри объекта, берётся ближайший следующий.

### Прыжки по структуре

| Клавиша | Действие |
| --- | --- |
| `]f` / `[f` | следующая / предыдущая функция |
| `]c` / `[c` | следующий / предыдущий класс |

## Комментарии

| Клавиша | Действие |
| --- | --- |
| `gcc` | закомментировать строку |
| `gc` + объект | например `gcaf` — функцию, `gcip` — абзац |
| `gc` в Visual | выделенное |

Символ комментария подбирается по месту: в `.tsx` внутри JSX получится
`{/* */}`, а в обычном коде того же файла `//`.

## Буферы, окна, вкладки

Три понятия, которые в других редакторах слиты в одно. В VS Code вкладка —
это и открытый файл, и его место на экране. В Neovim это три слоя.

| Что | Что это | Аналогия |
| --- | --- | --- |
| Буфер | открытый файл в памяти | сам файл |
| Окно | область экрана с буфером | смотровое окно в файл |
| Вкладка | раскладка окон | расстановка окон на столе |

**Буфер живёт независимо от окна.** Один буфер можно показать в двух окнах и
видеть начало и конец файла сразу. Закрыли окно — файл остался открытым.

Следствия, на которых обычно спотыкаются:

- `<leader>sx` закрывает окно — файл остаётся буфером и доступен по `Tab`;
- `<leader>bx` закрывает буфер — окно показывает соседний;
- `<leader>tx` закрывает вкладку — буферы все остаются;
- «файл открыт дважды» — это один буфер в двух окнах, правка видна в обоих.

Буферов за день накапливается много, и это нормально: они почти ничего не
стоят. Когда полоса вверху перестала помещаться — `<leader>bo`, закрыть все
кроме текущего.

Вкладки в Neovim — не файлы, а наборы окон. Используют их реже: обычно чтобы
отложить одну задачу с её раскладкой и заняться другой.

## Макросы

Запись последовательности действий и повтор её сколько нужно.

| Команда | Действие |
| --- | --- |
| `qa` | начать запись в регистр `a` |
| `q` | остановить запись |
| `@a` | выполнить записанное |
| `@@` | повторить последний макрос |
| `10@a` | выполнить десять раз |

Пример: в списке из тридцати строк нужно обернуть каждую в кавычки.

```
qa          начать запись
I"          в начало строки, вставить кавычку
Esc A",     в конец, кавычка и запятая
Esc j       на следующую строку
q           закончить запись
29@a        повторить для остальных
```

Правило: в макросе двигаться так, чтобы он работал из любого места — `0`, `I`,
`A`, `w`, а не «три раза вправо».

## Регистры

Несколько буферов обмена одновременно.

| Команда | Действие |
| --- | --- |
| `"ay` | скопировать в регистр `a` |
| `"ap` | вставить из регистра `a` |
| `"0p` | вставить последнее скопированное (не удалённое) |
| `:reg` | посмотреть содержимое всех регистров |

Зачем: `dd` затирает то, что вы копировали раньше, потому что удаление тоже
пишет в безымянный регистр. Регистр `"0` хранит именно скопированное, а не
удалённое.

### Системный буфер обмена

В конфиге стоит `clipboard = "unnamedplus"`, поэтому обычные `y` и `p`
работают с системным буфером напрямую: скопировали в nvim — вставляется в
браузер, и наоборот.

## Метки

Закладки внутри файла.

| Команда | Действие |
| --- | --- |
| `ma` | поставить метку `a` |
| `` `a `` | перейти к метке `a` |
| `'a` | перейти на начало строки с меткой |
| `:marks` | список меток |

Строчные буквы — метки внутри файла, заглавные работают между файлами.

## Как найти сочетание клавиш

Запоминать всё наизусть не нужно — конфиг подсказывает сам.

| Способ | Что покажет |
| --- | --- |
| нажать `<leader>` и подождать | список групп и команд под leader |
| `<leader>?` | сочетания только текущего буфера — в основном от LSP |
| `<leader>fk` | поиск по всем сочетаниям с фильтром по описанию |
| `:map` | полный список маппингов текстом |
| `:imap jj` | что назначено на конкретное сочетание в Insert |
| `:verbose map <Space>ff` | то же плюс файл и строка, где маппинг задан |

`:verbose` особенно полезен, когда клавиша делает не то, что ожидалось: он
покажет, какой плагин её перехватил.

Команды `g`-серии (`gd`, `gR`, `gcc`) в подсказке leader не видны — они не
начинаются с leader. Смотреть их через `<leader>?` или `<leader>fk`.
