# Neovim — отладка

Точки останова, пошаговое выполнение и просмотр переменных прямо в редакторе.
Клавиши всех остальных разделов — в [keys.md](keys.md).

`<leader>` — клавиша-префикс, какая именно назначена, указано в начале
[keys.md](keys.md).

---

## Клавиши

| Клавиша | Действие |
| --- | --- |
| `F4` | начать отладку |
| `F5` | запустить файл; во время отладки — продолжить |
| `F6` | пауза |
| `F9` | точка останова вкл/выкл |
| `F10` | шаг через |
| `F11` / `Shift+F11` | шаг внутрь / наружу |
| `<leader>db` | точка останова с условием |
| `<leader>dc` | выбрать конфигурацию запуска |
| `<leader>do` | шаг наружу |
| `<leader>dr` | консоль отладчика |
| `<leader>dt` | отладить тест под курсором — Go и Python |
| `<leader>du` | показать или скрыть панели |
| `<leader>dx` | завершить и закрыть панели |

`Shift+F11` проходит не через каждый терминал, поэтому у шага наружу есть
дубль `<leader>do`.

---

## Порядок работы

1. Откройте файл и поставьте курсор на нужную строку, `F9` — слева появится
   красная точка.
2. `F4` — запускается отладчик, программа останавливается на точке.
3. Смотрите переменные в панели слева, шагайте по коду `F10` и `F11`.
4. `F5` — дойти до следующей точки или до конца.
5. `<leader>dx` — завершить и убрать панели.

Когда программа доходит до конца, панели остаются на экране: в нижней видно
вывод программы. Закрываются они по `<leader>dx`.

---

## Панели

Раскладка штатная, как в документации dap-ui.

| Панель | Что показывает |
| --- | --- |
| слева | переменные, точки останова, стек вызовов, watch-выражения |
| снизу | вывод программы и консоль отладчика со строкой `dap>` |

Внутри панели переменных: `l` или `Enter` раскрывает ветку, `h` сворачивает,
`e` меняет значение, `r` отправляет выражение в консоль отладчика.

Значения простых переменных дополнительно дорисовываются серым прямо в строках
кода — это `nvim-dap-virtual-text`, в файле их нет.

---

## Запуск без отладчика

`F5` вне сессии просто выполняет текущий файл и печатает вывод в обычный
терминал (`Ctrl+\`). Команда подбирается по типу файла:

| Тип | Команда |
| --- | --- |
| go | `go run` |
| python | `python3` |
| javascript | `node` |
| typescript | `tsx` |
| sh | `bash` |
| lua | `lua` |

Файл перед запуском сохраняется.

---

## Языки

| Язык | Отладчик | Ставится |
| --- | --- | --- |
| Go | delve | mason, пакет `delve` |
| Python | debugpy | mason, пакет `debugpy` |
| Node и TypeScript | js-debug | mason, пакет `js-debug-adapter` |

Для Go и Python работает `<leader>dt` — отладка одного теста под курсором.

TypeScript запускается через `tsx`, без предварительной сборки. Если `tsx` в
системе нет, `F4` сообщит, что не нашёл модуль: поставьте его через
`npm i -g tsx` либо отлаживайте собранный `.js`.

---

## Конфигурации запуска

`F4` берёт первую конфигурацию для текущего языка и стартует без вопросов.
Полный список — по `<leader>dc`. Для Go их семь: обычный запуск, запуск с
аргументами, с флагами сборки, отладка пакета, подключение к процессу и две
для тестов.
