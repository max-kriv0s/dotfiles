# Neovim — план обучения

Порядок, в котором осваивать редактор, чтобы не хвататься за всё сразу.
Справочники — [basics.md](basics.md), [keys.md](keys.md), [scenaries.md](scenaries.md).

Главный принцип: **осваивать по одной вещи за раз и доводить до автоматизма.**
Десять приёмов, которыми пользуешься не задумываясь, полезнее ста прочитанных.

---

## Шаг 0. vimtutor

Встроенный интерактивный курс, около получаса. Запускается из терминала:

```bash
nvim +Tutor
```

Это не чтение, а работа руками в настоящем файле. Пройти стоит целиком и
до того, как читать что-то ещё — дальше всё опирается на эти движения.

При желании повторить — файл каждый раз создаётся заново, портить нечего.

## Шаг 1. Движения

Перемещаться по файлу, не касаясь стрелок.

- `w` / `b` / `e` — по словам
- `0` / `$` / `_` — по строке
- `gg` / `G` / `{число}G` — по файлу
- `{` / `}` — по абзацам
- `Ctrl+d` / `Ctrl+u` — полэкрана
- `/текст` и `n` / `N` — поиск как способ перемещения
- `zz` — поставить строку в центр

**Признак освоенности:** не тянетесь к стрелкам и мыши.

- [ ] освоено

---

## Шаг 2. Правка текста

Связка «оператор + движение»: `d` удалить, `c` заменить, `y` копировать.

- `dw`, `d$`, `dd` — удалить слово, до конца строки, строку
- `cw`, `C` — заменить слово, до конца строки
- `yy`, `p`, `P` — копировать и вставить
- `u`, `Ctrl+r` — отменить, вернуть
- `.` — повторить последнее действие

**Признак освоенности:** думаете не «удалить пять символов», а «удалить слово».

- [ ] освоено

---

## Шаг 3. Текст-объекты

`vif` вместо выделения построчно.

- `iw` / `aw` — слово
- `i"` / `a"`, `i(` / `a(` — внутри кавычек и скобок
- `if` / `af`, `ic` / `ac` — функция и класс (это уже treesitter)

**Признак освоенности:** `ci"` вместо ручного выделения строки в кавычках.

- [ ] освоено

---

## Шаг 4. Файлы и окна

- `Space ff`, `Space fw` — найти файл и текст
- `Tab` / `Shift+Tab` — переключение буферов
- `Space sv`, `Ctrl+h/j/k/l` — сплиты и переходы
- `Space ee` — дерево

**Признак освоенности:** открываете нужный файл за пару секунд, не вспоминая путь.

- [ ] освоено

---

## Шаг 5. Работа с кодом

- `gd`, `gR`, `K` — определение, использования, документация
- `Ctrl+O` / `Ctrl+I` — возврат
- `]d`, `Space d`, `Space ca` — ошибки и быстрые исправления
- `Space rn` — переименование по проекту

**Признак освоенности:** разбираетесь в незнакомом коде, не открывая поиск по тексту.

- [ ] освоено

---

## Шаг 6. Макросы и регистры

То, что превращает редактор в инструмент автоматизации.

- `qa` … `q`, `@a`, `@@` — записать и повторить макрос
- `"ay`, `"ap` — несколько буферов обмена
- `:reg` — посмотреть, что где лежит

**Признак освоенности:** вместо двадцати одинаковых правок записываете макрос.

- [ ] освоено

---

## Шаг 7. Метки и quickfix

- `ma`, `` `a `` — закладки внутри файла
- `Space fw` → `Tab` → `Alt+q` → `:cdo` — правка по всему проекту
- `:copen`, `:cnext` — работа со списком мест

**Признак освоенности:** массовая правка не пугает.

- [ ] освоено

## Что читать

### Дрю Нейл, «Практическое использование Vim»

Читать после `vimtutor`, когда базовые движения уже в пальцах. Книга построена
как 120 коротких приёмов: каждый — законченная техника с примером. Читается не
подряд, а по паре приёмов за раз, сразу пробуя в работе.

Главная мысль книги — «думать на языке редактора»: не «удалить пять символов»,
а «удалить слово», не «повторить двадцать раз», а «записать макрос».

- [ ] читаю
- [ ] прочитана

### `:help` — встроенная справка

Основной источник, когда конкретный вопрос уже сформулирован.

```vim
:help текст-объект
:help :cdo
:help lsp
```

`Space fh` ищет по справке нечётко, если не помните точного названия.
