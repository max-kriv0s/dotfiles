# Neovim — все сочетания клавиш

Справочник по нашей сборке. Пояснения и примеры — в [basics.md](basics.md),
рабочие сценарии — в [scenaries.md](scenaries.md).

`<leader>` — клавиша-префикс, у нас это `Space`. Задаётся в
`lua/core/keymaps.lua`. Запись `<leader>ff` означает: нажать префикс,
отпустить, нажать `f`, потом ещё раз `f`.

**Выход из Insert — `jj`.** `Esc` тоже работает. `jk` не назначено: в кириллице
оно даёт «ол», которое встречается в обычных словах.

**Русская раскладка** поддержана: `<leader>ые` делает то же, что `<leader>ws`.

Забыли клавишу — нажмите `<leader>` и подождите, или `<leader>fk` для поиска
по всему списку.

## Сохранить и выйти

Это не сочетания, а команды: двоеточие переводит в командную строку внизу
экрана, дальше команда и `Enter`.

| Команда | Действие |
| --- | --- |
| `:w` | сохранить |
| `:q` | закрыть окно; если оно последнее — выйти |
| `:wq` | сохранить и закрыть |
| `:x` | то же, но не трогает файл, если изменений не было |
| `:wa` | сохранить все изменённые файлы |
| `:qa` | закрыть все окна и выйти |
| `:wqa` | сохранить всё и выйти |
| `:q!` | выйти, отказавшись от изменений |
| `:qa!` | то же для всех файлов |
| `:e!` | перечитать файл с диска, свои правки выбросить |

Без двоеточия, прямо из Normal:

| Клавиша | Действие |
| --- | --- |
| `ZZ` | сохранить и закрыть — то же, что `:x` |
| `ZQ` | закрыть без сохранения — то же, что `:q!` |

`:w` спросит подтверждения, если файл изменился на диске; `:e!` не спросит
ничего и молча выбросит несохранённое. Подробнее — в разделе про `:e!`
в [README.md](README.md).

## Перемещение по файлу

*Встроено в Neovim. Подробнее с примерами — в [README.md](README.md).*

| Клавиша | Действие |
| --- | --- |
| `h` / `j` / `k` / `l` | влево / вниз / вверх / вправо |
| `w` / `b` | на слово вперёд / назад |
| `e` | в конец слова |
| `0` / `$` | в начало / конец строки |
| `_` | к первому непробельному символу строки |
| `gg` / `G` | в начало / конец файла |
| `{число}G` | на строку с этим номером |
| `{` / `}` | к предыдущему / следующему абзацу |
| `%` | к парной скобке |
| `Ctrl+d` / `Ctrl+u` | на полэкрана вниз / вверх |
| `zz` / `zt` / `zb` | строку с курсором в центр / наверх / вниз экрана |
| `/текст` | поиск вперёд, `?текст` — назад |
| `n` / `N` | следующее / предыдущее совпадение |
| `*` | искать слово под курсором |

## Текст-объекты

*Задаётся в `lua/plugins/treesitter.lua`.*

Используются с `v` (выделить), `d` (удалить), `c` (заменить), `y` (копировать).

| Объект | Что захватывает |
| --- | --- |
| `af` / `if` | функция целиком / её тело |
| `ac` / `ic` | класс целиком / его тело |
| `aa` / `ia` | аргумент с запятой / сам аргумент |
| `an` / `in` | узел синтаксиса шире / уже |
| `ih` | блок изменений git |

Перемещение по структуре:

| Клавиша | Действие |
| --- | --- |
| `]f` / `[f` | следующая / предыдущая функция |
| `]c` / `[c` | следующий / предыдущий класс |
| `]n` / `[n` | следующий / предыдущий узел |
