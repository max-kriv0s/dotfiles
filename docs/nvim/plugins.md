# Neovim — установленные плагины

Что стоит в сборке и зачем. Клавиши — в [keys.md](keys.md), рабочие сценарии —
в [scenaries.md](scenaries.md).

Версии зафиксированы в `lazy-lock.json`: на другой машине встанут ровно те же,
что здесь. Обновление — `:Lazy update`, оно перезапишет этот файл.

---

## Управление плагинами

| Плагин | Зачем |
| --- | --- |
| `lazy.nvim` | менеджер плагинов: ставит, обновляет, откладывает загрузку до первого использования |

`:Lazy` открывает список: что загружено, что нет, сколько занял старт.

## Внешний вид

| Плагин | Зачем |
| --- | --- |
| `tokyonight.nvim` | основа темы coolnight — палитра наша, движок его |
| `kanagawa.nvim` | вторая тема |
| `catppuccin` | третья тема |
| `lualine.nvim` | строка состояния внизу: режим, ветка git, путь, позиция |
| `bufferline.nvim` | полоса открытых буферов сверху |
| `nvim-web-devicons` | иконки типов файлов для дерева, полосы и поиска |
| `which-key.nvim` | подсказка по сочетаниям: нажали `Space` — видите варианты |
| `alpha-nvim` | начальная страница при запуске без файла |

Тема выбирается общим переключателем `theme` (см. [../theme.md](../theme.md)),
nvim подхватывает её без перезапуска.

Начальная страница показывается только при запуске без аргументов. Клавиши на
ней те же, что и в редакторе, — отдельных запоминать не нужно.

## Поиск и навигация по файлам

| Плагин | Зачем |
| --- | --- |
| `fzf-lua` | нечёткий поиск: файлы, текст по проекту, буферы, ошибки, справка |
| `neo-tree.nvim` | дерево файлов слева |
| `oil.nvim` | каталог как обычный буфер: переименование и создание файлов как правка текста |
| `plenary.nvim` | библиотека, на которой держатся другие плагины; сам по себе ничего не делает |
| `nui.nvim` | библиотека окон для neo-tree |

Дерево и oil решают разные задачи: дерево — посмотреть структуру, oil —
массово переименовать или разложить файлы.

## Языковые серверы и код

| Плагин | Зачем |
| --- | --- |
| `nvim-lspconfig` | готовые настройки подключения языковых серверов |
| `mason.nvim` | установщик серверов, линтеров и форматировщиков |
| `mason-lspconfig.nvim` | связывает mason и lspconfig: сервер поставлен — сервер включён |
| `mason-tool-installer.nvim` | доставляет то, что не является языковым сервером: prettierd, stylua, shfmt |
| `lazydev.nvim` | автодополнение по API самого Neovim при правке конфига |
| `schemastore.nvim` | схемы для JSON и YAML: подсказки в `package.json`, `compose.yaml`, GitHub Actions |

Что именно установлено из серверов — `:Mason`.

## Отладка

| Плагин | Зачем |
| --- | --- |
| `nvim-dap` | ядро: точки останова, шаги, сессии |
| `nvim-dap-ui` | панели переменных, стека и вывода |
| `nvim-dap-virtual-text` | значения переменных серым прямо в строках кода |
| `nvim-dap-go` | Go через delve, отладка одного теста |
| `nvim-dap-python` | Python через debugpy |

Node и TypeScript отлаживаются без отдельного плагина: адаптер `js-debug`
подключается к nvim-dap напрямую. Подробно — в [debug.md](debug.md).
