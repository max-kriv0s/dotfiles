# Terminal — Шпаргалка

Базовые команды Linux/macOS для разработки и диагностики места на диске.

---

## Навигация

| Команда | Действие |
| ------- | -------- |
| `pwd` | показать текущий каталог |
| `ls` | показать файлы |
| `ls -la` | показать все файлы, включая скрытые |
| `cd path` | перейти в каталог |
| `cd ..` | перейти на уровень выше |
| `cd ~` | перейти в домашний каталог |
| `open .` | открыть текущий каталог в Finder на macOS |

---

## Файлы и каталоги

| Команда | Действие |
| ------- | -------- |
| `mkdir name` | создать каталог |
| `mkdir -p a/b/c` | создать вложенные каталоги |
| `touch file.txt` | создать пустой файл |
| `cp from to` | скопировать файл |
| `cp -R from to` | скопировать каталог |
| `mv from to` | переместить или переименовать |
| `rm file.txt` | удалить файл |
| `rm -r dir` | удалить каталог |

С `rm` будь осторожен: команда удаляет без корзины.

---

## Чтение файлов

| Команда | Действие |
| ------- | -------- |
| `cat file` | вывести файл целиком |
| `less file` | открыть файл для просмотра |
| `head file` | показать начало файла |
| `tail file` | показать конец файла |
| `tail -f file` | смотреть лог в реальном времени |
| `sed -n '1,120p' file` | показать строки 1-120 |
| `sed -n '/text/p' file` | показать строки, где есть `text` |

В `less`: `q` выйти, `/text` поиск, `n` следующее совпадение.

## Поиск

| Команда | Действие |
| ------- | -------- |
| `rg text` | найти текст в файлах |
| `rg --files` | показать файлы проекта |
| `find . -name "*.lua"` | найти файлы по имени |
| `which nvim` | показать путь до команды |
| `command -v nvim` | показать путь до команды |

`rg` обычно удобнее и быстрее, чем `grep`.

## Symlink

Создать ссылку:

```bash
ln -s ~/dotfiles/lazygit/.config/lazygit ~/.config/lazygit
```

Проверить:

```bash
ls -la ~/.config | grep lazygit
```

Удалить symlink:

```bash
rm ~/.config/lazygit
```

Это удалит только ссылку, а не каталог в dotfiles.

## Место на диске

Показать свободное место:

```bash
df -h
```

Размер текущего каталога:

```bash
du -sh .
```

Размер папок внутри текущего каталога:

```bash
du -sh ./*
```

Размер папок в `~/.local`:

```bash
du -sh ~/.local/*
```

Размер кешей:

```bash
du -sh ~/Library/Caches/* ~/.cache/*
```

Размер neovim-данных:

```bash
du -sh ~/.config/nvim* ~/.local/share/nvim* ~/.local/state/nvim* ~/.cache/nvim*
```

## Поиск больших файлов

Найти крупные файлы в текущем каталоге:

```bash
find . -type f -size +100M
```

Найти крупные файлы в домашнем каталоге без скрытых системных каталогов:

```bash
find ~/Desktop ~/Documents ~/Downloads ~/Projects -type f -size +500M
```

Показать самые тяжелые элементы в текущем каталоге:

```bash
du -sh ./* | sort -h
```

На macOS можно поставить удобный интерактивный просмотрщик:

```bash
brew install ncdu
```

Запуск:

```bash
ncdu ~
```

## Права

```bash
ls -la          # посмотреть права
whoami          # текущий пользователь
chmod +x file   # сделать файл исполняемым
```

Пример из `ls -la`:

```text
-rwxr-xr--  user  group  file
```

```text
-     тип: файл. Для каталога будет d
rwx   права владельца
r-x   права группы
r--   права остальных
```

| Право | Число | Значение |
| ----- | ----- | -------- |
| `r` | `4` | читать |
| `w` | `2` | писать |
| `x` | `1` | запускать файл / входить в каталог |

Числа складываются:

| Права | Значение |
| ----- | -------- |
| `7` | `rwx` = `4+2+1` |
| `6` | `rw-` = `4+2` |
| `5` | `r-x` = `4+1` |
| `4` | `r--` = `4` |

Частые варианты:

```bash
chmod 644 file  # rw-r--r-- обычный файл
chmod 755 file  # rwxr-xr-x исполняемый файл или каталог
chmod 700 dir   # rwx------ приватный каталог
```

## Полезные проверки

```bash

echo $PATH
```
